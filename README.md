#**1. 🎮Hangman Game (Python)

## Description
This is a simple text-based Hangman game built using Python.  
The player has to guess the hidden word letter by letter before the attempts run out.

## Features
- Displays logo "HANGMAN GAME" 
- Uses a list for words
- Random word selection
- User input for guessing letters
- Limited attempts system
- Displays hungman images for each attempt
- Displays progress of the word
- Simple console-based gameplay

## Concepts Used
- Python strings
- Loops (while / for)
- Conditional statements (if-else)
- Lists
- Random module
- Input/Output handling

## How to Play
1. Run the Python file
2. Guess one letter at a time
3. You have limited chances to guess the word
4. Guess the full word before attempts run out
